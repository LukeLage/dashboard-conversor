# Conversor de Real para Moedas Estrangeiras

## Visão Geral
Esse reposotório faz parte de um projeto pessoal para criação de um portfólio voltado para banco de dados.
Seu objetivo é auxiliar nos estudos e na prática para aprimoramento de habilidades voltadas à análise e visualização de dados.
Os dados usados nesse dashboard incluem: 
  * Taxa de conversão de real para as seguintes moedas:
    1. Dólar;
    2. Euro;
    3. Libra;
    4. Yuan;
    5. Peso Argentino;
    6. Dólar Canadense;
    7. Peso Chileno;
    8. Peso Mexicano

## Instruções de Uso
1. Clone esse repositório em seu computador local
2. Instale as bibliotecas necessárias para a execução desse código digitando a seguinte linha em seu terminal:
    ```
   pip install streamlit pandas matplotlib
    ```
4. Execute o código digitando a seguinte linha em seu terminal:
    ```
    streamlit run dashboard-conversor.py
   ```
6. Clique no link que seu navegador oferecerá
7. Para ter certeza que os dados estão atualizados, clique no botão de atualizar taxas e aperte F5
